바뀐 점
- 버스 정보 요청이 모두 서버(relay)를 거칩니다. 앱에 API 키가 없습니다.
- 정보를 못 불러오면 "버스 정보를 불러오지 못했습니다" / 하루 한도면 "오늘은 조회가 많아…" 안내
- 도시 판별 개선(성남 기본값 제거, TAGO 도시 목록 사용)
- 내부 정리: Swift 6, @Observable, 네트워크 계층 교체, 권한 API 교체

꼭 확인
1. 첫 실행 권한 팝업 4종(위치·카메라·마이크·음성 인식), 거부 시 안내 시트
2. 홈에 주변 정류장 표시 → 버스 번호 검색 → 노선 → 도착정보 카운트다운
3. 마이크 버튼 음성 검색
4. 버스 인식 카메라: 기울기 안내 음성·햅틱, 인식 박스, 내 버스 감지 피드백, 화면을 여러 번 들어갔다 나오기
5. VoiceOver 켜고 화면 읽기와 실패 안내
6. 서울·경기 외 지역(가능하면 다른 시·도)에서 정류장과 도착정보
